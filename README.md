## 📥 Como instalar

1. Instala a extensão **Tampermonkey** no navegador
2. Clica aqui para instalar o script:
   https://github.com/Haypper/H4YZ1NBetter/raw/main/H4YZ1N-Better-Cloud-UNIFIED-REMOTE-XCLOUD.user.js
3. Clica em **Install**
4. Abre https://www.xbox.com/play e usa o painel 🚀
